# DevOps Project: React To-Do List (JSX)

This is a simple To-Do List application built with React (using JSX), Vite, and Tailwind CSS. It serves as the baseline application for a comprehensive DevOps course, demonstrating best practices in project planning, repository security, and Continuous Integration.

## Features

- Add, complete, and delete tasks.
- Live counter for remaining tasks.
- Saves all tasks to the browser's `localStorage`.

## Project Setup & Local Development

To run this project locally, you need [Node.js](https://nodejs.org/) (v18+) installed.

1.  **Clone the repository:**

    ```sh
    git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
    cd YOUR_REPO_NAME
    ```

2.  **Install dependencies:**

    ```sh
    npm install
    ```

3.  **Run the development server:**
    ```sh
    npm run dev
    ```
    The app will be running at `http://localhost:5173`.

## Available Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run lint`: Lints the code using ESLint.
- `npm run test`: Runs the unit tests using Vitest.
